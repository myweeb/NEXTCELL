# NEXTCELL — site base

Site estático responsivo feito com HTML, CSS e JavaScript, usando a identidade amarela, preta e branca.

## Arquivos
- `index.html`: estrutura e conteúdo.
- `style.css`: visual e responsividade.
- `script.js`: menu mobile e ano automático no rodapé.
- `assets/nextcell-logo.svg`: logo vetorial editável.
- `assets/phone-repair.svg`: ilustração vetorial de celular para a seção principal.

## Publicar no GitHub
Extraia o ZIP e envie todos os arquivos mantendo as pastas. Para GitHub Pages, em Settings → Pages, selecione a branch principal e a pasta raiz.
